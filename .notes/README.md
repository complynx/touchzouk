# Touchzouk Memento

Living repo memory. Keep durable knowledge preventing error or wasted work. Keep `AGENTS.md` small.

## Layers

1. `AGENTS.md`: tattoos. Rules needed before nearly every task or before easy harmful action.
2. `.notes`: supporting knowledge. Architecture, commands, invariants, checks, stable pitfalls for matching tasks.

Start here. Open relevant topic notes only. Add or split topic only when routing becomes hard.

## Topics

- [Frontend and audio](frontend-audio.md): player ownership, cache versions, muted browser QA, seeker checks.
- [Verification and CI](verification-ci.md): local gates, workflow order, lint limits, local false signals.
- [Ordering, data, and deployment](ordering-data-deployment.md): persisted order, concurrency, migration review, rollout assumptions.

## Maintenance

- Write all tattoos and memento notes in Caveman style: terse, exact, no filler. Preserve technical terms, commands, numbers, and every negative.
- Add repo-specific knowledge only. Must prevent likely error or materially shorten future work.
- Update existing note first. Add note only when no topic fits. Split only when scan becomes hard.
- Keep evidence, invariants, decisive commands, stable pitfalls.
- Drop task chronology, status, temp paths, run IDs, one-off output.
- Promote note to tattoo only when nearly every task needs it or omission risks easy harm.
