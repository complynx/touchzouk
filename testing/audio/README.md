# Public-domain demo audio

`cc0-chill-beat.ogg` is a local-development preview of **Chill Beat**
by Wikimedia Commons user Maddy.

- Source: https://commons.wikimedia.org/wiki/File:Chill_Beat.ogg
- Original file: https://upload.wikimedia.org/wikipedia/commons/9/9f/Chill_Beat.ogg
- License: CC0 1.0 Universal Public Domain Dedication
  (https://creativecommons.org/publicdomain/zero/1.0/)
- Modification: renamed for use as a stable seed asset; the audio bytes are
  otherwise identical to the original Wikimedia Commons download.

The source page identifies the uploader as the copyright holder and explicitly
dedicates the recording to the public domain under CC0. This audio is used only
as seeded demo content and is not a Touchzouk performance.

`cc0-fur-elise.ogg` is a recording of **Für Elise**, performed by Wikimedia
Commons user Gaodifan.

- Source: https://commons.wikimedia.org/wiki/File:FurElise.ogg
- Original file: https://upload.wikimedia.org/wikipedia/commons/7/7b/FurElise.ogg
- License: CC0 1.0 Universal Public Domain Dedication
  (https://creativecommons.org/publicdomain/zero/1.0/)
- Modification: remuxed without re-encoding to add the `Für Elise` title tag.

`public-domain-original-rags.ogg` is **Original Rags** by Scott Joplin,
performed by James Brigham.

- Source: https://commons.wikimedia.org/wiki/File:Original_Rags_-_Scott_Joplin_-_1899.ogg
- Original file: https://upload.wikimedia.org/wikipedia/commons/9/9f/Original_Rags_-_Scott_Joplin_-_1899.ogg
- License: Public Domain Mark 1.0; the source page identifies both the
  composition and recording as free of known copyright restrictions.
- Modification: remuxed without re-encoding to add the `Original Rags` title
  tag.

All three files are test fixtures. None is presented as a Touchzouk recording.
